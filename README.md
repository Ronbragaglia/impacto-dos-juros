# Impacto dos Juros no Financiamento

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python&logoColor=white) ![Topic](https://img.shields.io/badge/Topic-finance-green) ![License](https://img.shields.io/badge/License-MIT-yellow)

## Descrição

Calculadora de financiamento imobiliário usando a Tabela Price para calcular a parcela mínima e o total pago com diferentes taxas de juros anuais e visualizar o impacto no longo prazo.

## Funcionalidades

- Cálculo de parcelas pela Tabela Price
- Comparação entre diferentes taxas de juros anuais
- Cálculo do total pago ao longo do financiamento
- Visualização gráfica do impacto dos juros
- Útil para educação financeira e simulações de crédito

## Stack Tecnológico

| Tecnologia | Descrição |
|---|---|
| Python | Linguagem principal |
| NumPy | Cálculos financeiros precisos |
| Matplotlib | Gráficos de comparação |

## Como Usar

1. Instale as dependências: `pip install numpy matplotlib`
2. Execute: `python impacto_juros.py`
3. Informe o valor do imóvel, prazo e taxas para comparação
